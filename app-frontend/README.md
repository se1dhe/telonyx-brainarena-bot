# Roman Codex Quiz UI

Премиальный светлый UI-набор для Telegram Mini App / Web App квиза в эстетике Рима, Архимеда, Цезаря, истории, лавровых венков, мрамора, пергамента и интеллектуального статуса.

В архиве:
- `react/` — основной production-ready прототип на React + TypeScript + Vite + Tailwind + Framer Motion.
- `vue/` — альтернативный прототип на Vue 3 + TypeScript + Vite + Tailwind + Framer Motion.
- `SKILLS.md` — требования к навыкам и продуктовой дисциплине.
- `AGENTS.md` — роли AI/Code agents для проекта.
- `PROMPT_CODEX.md` — системный промт для Codex.
- `DESIGN_SYSTEM.md` — дизайн-система и правила стиля.

## Рекомендация

Основным вариантом брать `react/`, потому что для Telegram Mini App, анимаций, компонентной системы, будущих кабинетов и A/B тестов React даст больше готовой экосистемы.

Vue-версия оставлена как чистая альтернатива, если захочешь делать фронтенд быстрее и компактнее.

## Запуск React

```bash
cd react
npm install
npm run dev
```

## Запуск Vue

```bash
cd vue
npm install
npm run dev
```
