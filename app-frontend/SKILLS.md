# SKILLS.md

# Roman Codex Quiz — Skills Matrix

## Product Goal

Создать Telegram Mini App / Web App квиз для аудитории премиальной интеллигенции: история, логика, наука, культура, философия, дуэли умов, IQ-рейтинг, хроники, ранги и ежедневные ритуалы.

Приложение не должно выглядеть как дешёвая мобильная игра. Оно должно ощущаться как личная академия, клуб, сенат или библиотека.

---

## 1. Product Skills

### Retention Design

Нужно уметь проектировать:
- ежедневный ритуал на 3–7 минут;
- streak без давления;
- умное повторение ошибок;
- мягкие daily rewards;
- прогресс по главам;
- сезонные лиги;
- персональные хроники достижений;
- редкие трофеи: венки, печати, короны, титулы.

### Quiz Design

Нужно уметь делать:
- честные вопросы без мусорных вариантов;
- объяснение правильного ответа;
- уровни сложности;
- тематические курсы;
- квизы по эпохам;
- дуэли 1v1;
- асинхронные PvP-матчи;
- “вопрос дня”;
- “загадку сфинкса”;
- интеллектуальные цепочки: 3–5 вопросов одной темы.

### Monetization Design

Подходящие механики:
- Premium/Patrician subscription;
- дополнительные попытки в дуэлях;
- расширенная статистика;
- редкие профили/рамки/печати;
- эксклюзивные курсы;
- сезонный пропуск “Codex Pass”;
- кастомизация профиля;
- приватные клубы/лиги.

Запрещённый тон:
- “купи буст, стань богом”
- агрессивные pay-to-win механики
- шумная казуальная монетизация

### Social Design

Полезные механики:
- интеллектуальные клубы;
- друзья;
- дуэли;
- совместные курсы;
- таблица сената;
- недельная лига;
- шаринг результата;
- приглашение в клуб;
- реферальный титул.

## 2. Frontend Skills

### Junior

Должен уметь:
- React/Vue component basics;
- TypeScript basics;
- Tailwind basics;
- responsive layout;
- Telegram Mini App viewport basics;
- работа с SVG.

### Middle

Должен уметь:
- дизайн-система;
- токены темы;
- Framer Motion / Vue transitions;
- headless components;
- accessible UI;
- сложные карточки;
- state management;
- API integration;
- optimistic UI.

### Senior

Должен уметь:
- масштабируемая архитектура фронтенда;
- feature-sliced design;
- UI performance;
- A/B-ready screens;
- design tokens;
- animation system;
- Telegram SDK;
- аналитика событий;
- production build pipeline.

## 5. Content Skills

Контент должен быть:
- интеллектуальным;
- точным;
- без кликбейта;
- с коротким объяснением ответа;
- с историческим контекстом;
- в премиальном тоне.

Пример хорошего тона:
> “Этот вопрос проверяет не память дат, а понимание политической логики Рима.”

Пример плохого тона:
> “Ого! Ты слил вопрос! Купи буст!”
