# Brain Arena WebApp

React/Vite Telegram Mini App для Brain Arena.

## Запуск локально

```bash
npm ci
npm run dev
```

## Railway

Root Directory:

```text
apps/webapp
```

Build Command:

```bash
npm ci && npm run build
```

Start Command:

```bash
npm run start
```
